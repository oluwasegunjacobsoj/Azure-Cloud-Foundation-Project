Shared Responsibility Model
This defines which security responsibilities belong to Microsoft Azure and which belong to the customer

For the deployed Storage Account:

Microsoft Azure responsibilities:
a. Physical data center security 
b. Hardware maintenance
c. Network infrastructure protection
d. Availability of cloud services

Customer responsibilities:
a. Managing access permissions
b. Configuring Security settings
c. Protecting account credentials
d. Monitoring resource usage
